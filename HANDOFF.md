## Gotchas
* Set `OMP_NUM_THREADS` per job when running jobs in parallel (4–5× slowdown otherwise).
* `third_party/` must exist for B0/B1/PIVlab; tests skip (not fail) without it.
* PIVlab `*spline` deformation does not run in Octave's `interp2` (MATLAB only).
